# 唐宋之际形势图

[![中文](https://img.shields.io/badge/lang-%E4%B8%AD%E6%96%87-red.svg)](README.md) [![English](https://img.shields.io/badge/lang-English-blue.svg)](README.en.md)

安史之乱至宋初（755–979）的交互历史地图：39 个时间节点的藩镇与政权疆域，382 处州府城邑的古今地名对照，燕云十六州的专门标注，黄巢转战的行军路线，以及 64 处都城行在、63 场战役、26 处关隘、34 项事件、44 条山脉、百余条河湖与周边诸族。界面中英双语，地图右上角「中 | EN」切换。

## 三、本地构建

改了史料内容（`content/`）或参数（`src/config.py`）之后才需要重新构建。需要 **Python 3.9 或更新版本**。

**macOS / Linux**

```bash
cd tangsong-map
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py --open
```

**Windows（PowerShell）**

```powershell
cd tangsong-map
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py --open
```

完整构建约 1 分钟，完成后会用浏览器打开新生成的 `docs/index.html`。

> 没有 Python？macOS 可用 `brew install python` 或到 python.org 下载；Windows 从 python.org 安装时勾选 “Add python.exe to PATH”。
> PowerShell 若提示禁止运行脚本，先执行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，或者跳过虚拟环境，直接 `py -m pip install -r requirements.txt` 再 `py run.py --open`。

| 命令 | 作用 |
|---|---|
| `python run.py` | 底图缺失则下载 → 计算疆域 → 拼装 HTML |
| `python run.py --html` | 只重新拼装 HTML（只改了 `src/template.html` 时用，不到 1 秒） |
| `python run.py --draft` | 英文有缺译或过期时也照常生成（缺译处显示中文）；默认会报错停下，见“七、英文版” |
| `python run.py --open` | 构建完后在浏览器中打开 |
| `python run.py --preview 805,820` | 额外画出这几个节点的疆域草图到 `build/preview.png`，便于检查归属是否填错 |
| `python tools/preview.py 895,907 100,125,20,42` | 只画草图，可指定经纬范围 |
| `python tools/snapcheck.py 903` | 不必跑完整构建，一秒列出某几个节点里每个单位领哪些州 |
| `python tools/snapcheck.py --diff 存档.json` | 与先前用 `--dump` 存下的解析结果比对，补节点后确认原有节点没被带偏 |
| `python tools/i18n.py status` | 查英文缺译、过期的条数 |
| `python tools/screenshot.py` | （可选，需 playwright）无头浏览器截图并检查脚本错误 |

压缩包里已经带了底图数据（`geodata/ne/`，约 31 MB），离线也能构建。如果删掉了，`run.py` 会自动从 GitHub 下载固定版本。

同一环境下，同一份输入的构建结果逐字节一致，可以放心用 git 追踪改动。

想用本地服务器预览（可选，不是必需的）：

```bash
python -m http.server -d docs 8000
# 浏览器打开 http://localhost:8000/
```

构建完成后，把 `docs/index.html` 一起提交并推送到 `main`，线上网页会自动更新。

## 五、工作原理

```
content/*.txt, *.py ─┐
                     ├─► build.py ─► build/geo.json + data.json ─► assemble.py ─► docs/index.html
geodata/ (底图) ─────┘                                              ▲    ▲
                                              src/template.html ──┘    └── content/en/*.json
```

### 1. 为什么疆域要“算”出来

藩镇和五代十国没有现成的边界数据。史书能确定的是“某年某州属某镇”，而唐代州界大体“随山川形便”。所以这里的做法是：

1. 只手写**州 → 藩镇 → 政权**的归属（`snaps.txt`）；
2. 用一张“通行代价”地图让计算机推出州与州之间的分界，让分界尽量落在山脊和大河上。

### 2. `build.py` 的步骤

1. **读种子**：`seeds.txt` 里 457 个点。类型 `z` 是州府，`c` 是城邑或外域地名，`r` 是只用来占地、不在图上显示的区域辅助点（如“羌塘”“西伯利亚1”）。
2. **解析时间节点**：`snaps.txt` 是一个小型声明式语言（语法见下文）。每个 `@年份` 块继承上一节点的全部归属，只写变化的部分。
3. **海陆栅格**：把 64°×39.5° 的范围切成 0.08°（约 8 km）的格子，共 800 × 494 ≈ 40 万格。大湖当作水面。
4. **代价栅格**：每格基础代价 1。
   - `items.RANGES` 里的山脉沿脊线“烧”出一道高斯形高代价带，主干山脉峰值 +9。
   - Natural Earth 的山地多边形整体加一点代价。
   - 长江 +7，黄河（含唐宋故道）、淮河（含古下游）各 +3.5。
   - 海面为无穷大。
5. **多源最短路**：把所有种子作为源点，在 8 邻接网格图（约 31 万个陆地格、250 万条有向边）上跑一次 `scipy.sparse.csgraph.dijkstra(min_only=True)`。每个格子归“代价距离”最近的州。
   - 这相当于一张**加权 Voronoi 图**，边界会被山脊、河道吸过去。
   - 代价距离超过 `MAX_REACH` 的格子算无主地，比如大漠深处、青藏腹地。
6. **生成多边形**：对每个节点：
   - 先按“州 → 单位”给格子上色，得到藩镇级和政权级两层；
   - 再向海面外延 4 格，海岸线在前端用陆地轮廓剪裁，不会留缝；
   - 经高斯平滑（σ = 1.15 格）后，用 marching squares（`skimage.measure.find_contours`）描出 0.5 等值线；
   - 最后用 Douglas–Peucker 简化。
   - 注记点取最大连通块的“不可达极点”（距离变换最大值处）。
7. **配色**：
   - 在 OKLCH 色彩空间里预设三档明度 × 24 个色相，彩度只有 0.065–0.075，所以颜色都是低饱和的。
   - 唐、吐蕃、回鹘、南诏、渤海、契丹、新罗、宋用固定色。
   - 其余单位按“全部节点中出现过的邻接关系”做贪心着色，邻居多的先挑，每次挑与已着色邻居色差最大的颜色。
   - 已发布单位的颜色记在 `content/colors.lock.json`，构建时优先采用：补节点、加单位只给新单位选色，原有颜色（包括与《宋辽夏金元形势图》979 年节点共用的颜色）不变。
   - 深色主题统一提亮。
8. **底图与条目**：
   - 海岸、今国界、湖泊、荒漠都来自 Natural Earth。
   - 河流按 `items.NE_RIVERS` 映射成唐代古名，比如 Huang 映射为“河”、Hong 映射为“富良江”。
   - 唐宋黄河故道、古济水、淮河古下游、运河是手绘折线，郑州以东的今黄河下游画成虚线。
   - 坐标 ×100 取整后差分编码。底图加 39 期疆域合计约 1 MB（原始底图 31 MB）。

### 3. 前端（`src/template.html`）

- **零依赖**：原生 JavaScript + SVG，无框架、无地图库。
- **投影**：Albers 等积圆锥投影，标准纬线 25°N、47°N，中心 104°E、35°N。
- **图层（自下而上）**：陆地 → 荒漠点纹 → 疆域填色 → 割据斜线 → 政权粗边界 → 湖泊 → 今省界 → 今国界 → 山脉 → 河流 → 运河 → 点符号与注记。
- **注记避让**：每帧把所有注记按优先级排序（选中项 > 疆域名称 > 都城 > 藩镇治所 > 战役 > 大河 > 关隘 > ……），每个注记依次尝试几个候选位置，都与已放置的注记重叠就不画。不同缩放级别有显示阈值，放大后才出现州名与今地。
- **交互**：
  - 拖动、滚轮或双指缩放；悬停显示提示，点击选中。
  - 右侧索引与地图联动。
  - 检索同时匹配古名、今名和名称沿革，中英文都收，英文忽略附加符号（输入 ngo quyen 可找到 Ngô Quyền）。
  - 时间轴可以播放（播放键下方切换 1× / 2× 倍速），键盘 ← → 切换节点，Esc 取消选中。
  - 可以切换“藩镇 / 政权”着色，图层可以逐项开关。
  - 另有年表、对照表两个视图。
- **随时间变化的标记**：每个时间节点涵盖“上一节点之后至本节点”的年份（如 851 年节点涵盖 845–851 年）。
  - 战役、事件和行军路线只显示落在本期的，时间轴下方列出本期战役，点一下就能定位。
  - 在索引里点其他时期的战役，时间轴会自动跳到那一期。
  - 都城只显示当时的都城和已经做过都城的旧都，后来才成为都城的地方不会提前出现。
- **行军路线**：黄巢转战（875—884）逐点记到达年份，地图只画到当前节点为止：本期走过的一段画实线加箭头，此前走过的画虚线；点路线或时间轴下的“行军”按钮，整条路线收进视野，索引里列出全程。在 `items.ROUTES` 里照格式加一条就能画别的路线。
- **燕云十六州**：938 年及以后的节点用红色虚线圈出十六州的范围，点线分出山前七州、山后九州；959 年起注明瀛、莫二州归周。
  - 范围线由十六个州（加上瓦桥、益津两关一带）的栅格并集描出，算法与疆域相同。
  - 点范围线、时间轴下的“要地”按钮或索引里的“重要地域”可以选中：整片高亮，十六州全部显示州名与今地，右侧给出割让经过和完整名单。
  - 在 `items.REGIONS` 里照格式加一条，就能标注别的地域（如河湟、关南）。
- **中 / 英**：地图右上角切换，选择记在浏览器里；网址加 `#en` 直接打开英文。英文模式下地图只标英文，悬停说明、索引、年表、对照表在英文名后附小号汉字原名；英文注记按实际字宽避让，长国名在疆域内折成两行。
- **主题**：颜色全部是 CSS 变量，跟随系统深浅色。每个单位的颜色是 `--u-<序号>`，由 `assemble.py` 注入。

### 4. `assemble.py`

先检查英文：有缺译或过期（中文改过而英文没跟着改）就报错停下，加 `--draft` 才放行。再把英文并入数据（政权 `ne`、州府 `ne`/`mode`、条目 `e{…}`、节点 `erae`/`te`/`de`），前端按当前语言取字。

模板里有 4 个占位符：`__GEO__`、`__DATA__`、`__UCSS_LIGHT__`、`__UCSS_DARK__`。脚本把它们替换成数据和颜色变量，再包上 `<!doctype html>` 等文档外壳。

## 六、常见修改

**改某州某年的归属**：在 `snaps.txt` 对应年份块里加一行。例如 805 年把宿州划给武宁：

```
武宁{徐州}: 徐州 泗州 濠州 宿州
```

**新增一个州**：

1. 在 `seeds.txt` 加一行：`宁州 107.92 35.50 甘肃宁县`
2. 在 `snaps.txt` 的 `@755` 块里把它分给某个单位（第一个节点必须给每个种子定归属，否则构建时会打印 `unassigned` 警告）
3. 运行 `python run.py --preview 755`，确认疆域没有异常

**州名改名**：在 `seeds.txt` 该行加 `N=0:旧名,年份:新名`，如 `N=0:汴州,907:开封府`。

**新增时间节点**（例如 790 年）：在 `snaps.txt` 里 `@787` 与 `@794` 之间插入：

```
@790 | 贞元六年 | 北庭陷没 | 说明文字……
吐蕃: 庭州 轮台 弓月城 准噶尔
```

前端会自动多出一个刻度。因为每个节点都从上一节点继承，插入的节点会改变下一节点的起点：插入前先 `python tools/snapcheck.py --dump build/snap-before.json` 存一份，插入后用 `--diff build/snap-before.json` 比对；原有节点有不该变的地方，就在下一节点里把归属、显示名（写空 `[]` 即删去）、治所写回去。

**加战役、关隘、事件**：在 `items.py` 的 `BATTLES`、`PASSES`、`EVENTS` 里照格式加一条元组。战役和事件会按年份自动归入对应的时间节点；持续多年的事件，在 `EVENT_END` 里写上结束年份。

**加行军路线**：在 `items.py` 的 `ROUTES` 里加一条：名称、今地、年代、说明，以及逐点的 `[经度, 纬度, 到达年, 地名]`。路线按到达年份自动归入各期。

**加政权或藩镇**：在 `units.py` 用 `S(...)`（政权）、`Z(...)`（藩镇）、`T(...)`（部族）加一条，再在 `snaps.txt` 里使用它的键。

**边界不该翻过某座山**：在 `items.RANGES` 里加这条山脉的脊线坐标，并把最后一位设为 `1`（主干，代价更高）。

**改颜色**：在 `content/colors.lock.json` 里改该单位的 OKLCH 三个数，或删掉那一行让它重新选色；`src/config.py` 里的 `PRESET_COLORS`、`PALETTE_LEVELS` 只影响不在锁里的单位。

**只改页面样式或交互**：编辑 `src/template.html`，然后运行 `python run.py --html`。

**改了中文以后**：对应的英文要一起改（见“七、英文版”），否则构建会报“过期”停下。

### `snaps.txt` 语法速查

```
@年份 | 年号 | 标题 | 说明                      开始一个时间节点（继承上一节点）
单位: 州 州 州                                  把这些州划给单位
单位[显示名]{治所}>所属政权: 州 ……              同时设定本期显示名、治所、隶属（三者都可省略）
单位[新显示名]:                                  只改名，不动辖区
单位[]:                                         删去此前设的显示名，恢复默认名称
单位: @另一单位                                  把“本节点开始时”属于另一单位的州全部划过来
单位: @另一单位@年份                             把“某年节点结束时”属于另一单位的州划过来
·: 州 州                                        设为无主
割据: 单位 单位 ……                               本期不受朝命的藩镇（地图加斜线），整行替换上期
# 注释
```

“所属政权”缺省时取 `units.py` 里的默认值：藩镇默认属唐，政权、部族属自己。显示名、治所、隶属一经设定，会延续到后面的节点，直到再次改写。

## 七、英文版

中文是源文本。每一条要显示的中文都有一个键，英文按同样的键写在 `content/en/` 下：

| 文件 | 内容 | 键 |
|---|---|---|
| `units.json` | 政权、藩镇、部族：全称 `n`、地图短名 `s`（可省）、说明 `note` | 单位键 |
| `labels.json` | 节点里的当年别名，如“魏博（罗弘信）” | 中文别名 |
| `seeds.json` | 州府城邑：今地 `mod`、各时期名称 `n` | 点的 ID |
| `items.json` | 条目：`old` `mod` `note` `yt` `sides` `cmd`，燕云分区 `g`，行军路线地名 `p` | `类别:古名`，同名条目后加 `@年份` |
| `snaps.json` | 时间节点：年号 `era`、标题 `t`、说明 `d` | 年份 |
| `misc.json` | 今省名 | 中文名 |

`zh.lock.json` 记着每条英文所据中文的指纹（sha1 前 10 位）。改了中文而没改英文，构建时就报“过期”。

改完英文的流程：

```bash
python run.py --html          # 默认严格：有缺译或过期就停下并列出数量
python tools/i18n.py todo     # 逐条列出缺译、过期的中文
# ……补改 content/en/*.json ……
python tools/i18n.py lock     # 登记新的中文指纹
python run.py --html
```

## 八、调参（`src/config.py`）

| 参数 | 默认 | 作用 |
|---|---|---|
| `FIRST` | 820 | 打开网页时显示的时间节点 |

| `MAX_REACH` | 7.5 | 超过此代价距离的格子算无主地 |
| `SMOOTH_SIGMA` | 1.15 | 边界平滑程度 |
| `SIMPLIFY_TERR` | 0.025 | 边界折线简化（越大越粗略、文件越小） |
| `PRESET_COLORS` | — | 固定色的政权（OKLCH） |

## 九、资料与可靠程度

- **底图**：[Natural Earth](https://www.naturalearthdata.com/) 1:10m 矢量数据（公有领域），固定在提交 `ca96624`。
- **今省界**：沿用此前《河陇西域古今地名对照图》中的简化省界。
- **史料**：归属与说明据两《唐书》、《资治通鉴》、新旧《五代史》，并参照谭其骧《中国历史地图集》第五册大意。
- **局限**：
  - 疆域边界是由州府归属推算的示意线，不是考证出的历史界线。
  - 西域、青藏、漠北、东北的种子点较稀，那里的边界尤其粗略。
  - 共 39 个节点，版图平静的年份不设节点（如 822—844 年），节点之间的逐年变化没有画出来。
  - 古河道是按文献走向手绘的近似线。
  - 有争议的事项在条目说明里注了“一说”：8 世纪末 9 世纪初西域各城的归属，784 年义武、横海的辖州，947 年辽军在中原的实际控制范围等。
  - 英文照中文翻译，译名体例见 `content/en/GLOSSARY.md`；月份是农历，不换算公历。
